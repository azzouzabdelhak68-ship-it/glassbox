# Getting Support for GlassBox

Thank you for using GlassBox! Here are the best ways to get help, ask questions, or report issues:

---

## 1. Ask Questions & Discuss Research

* **[GitHub Discussions](https://github.com/azzouzabdelhak68-ship-it/glassbox/discussions)**: The best place for:
  * Asking "how-to" implementation questions.
  * Sharing mechanistic interpretability findings and steering experiments.
  * Brainstorming new watchlist presets and model architectures.

---

## 2. Report Bugs & Request Features

* **[GitHub Issues](https://github.com/azzouzabdelhak68-ship-it/glassbox/issues)**: Use this for:
  * Bug reports (please include your GPU model, PyTorch version, and a minimal reproducible script).
  * Requests for new model architecture adapters (e.g. new GQA/MLA transformer layers, state-space models).
  * Feature suggestions for the flight store, steering engine, or Calm HTML Viewer.

---

## 3. Read the Documentation

Before opening an issue, check the comprehensive documentation portal:
* **[Master Documentation Hub](docs/README.md)**: Full index of guides and technical specs.
* **[Steering & Ablation Guide](docs/STEERING_GUIDE.md)**: How to use real-time activation steering and neuron clamping.
* **[Qwen3.8-27B Case Study](docs/DISCOVERY_QWEN_SAFETY.md)**: Empirical findings from our A100 SXM4-80GB stretch test.
* **[System Architecture](docs/ARCHITECTURE.md)**: Deep dive into non-blocking async DMA and ring buffer internals.

---

## 4. Academic Citation & Research Collaboration

If you are using GlassBox in an academic paper, you can cite this repository directly using the **"Cite this repository"** button in GitHub's right sidebar (powered by [`CITATION.cff`](CITATION.cff)).
